# Validation evidence checklist

- [ ] Proxmox VM inventory
- [ ] Snapshot created and rollback result
- [ ] Backup restore task log
- [ ] Windows Server AD DS role and domain controller verification
- [ ] DNS resolution tests
- [ ] User, computer and OU objects (sanitized)
- [ ] Domain-joined Windows client and successful domain login
- [ ] Group Policy screenshot or note on limitations
- [ ] Remote Desktop test
- [ ] Windows access control evidence
- [ ] Linux connectivity and administration
- [ ] Zabbix dashboard and monitoring host
- [ ] Recent Zabbix item data and timestamps

Use real screenshots. Blur credentials, sensitive names and any non-public network details before publishing.
